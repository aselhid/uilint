# uilint Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CLI that loads a web page in Chromium, measures every visible box, and reports near-miss spacing, alignment, size and overflow problems as text an agent can fix.

**Architecture:** A plain-JS script injected into the page extracts "visual boxes" (text runs, media, controls, styled surfaces) with locators. Pure Node rule modules turn a snapshot of boxes into findings. A report layer merges findings across viewports, applies the owner's ignore file and baseline, collapses repeats, and formats text or JSON. The CLI wires these together and sets the exit code.

**Tech Stack:** TypeScript (ESM, `strict`), Node 20+, `playwright` (library, Chromium), `commander` for argv, `tsx` (its `tsImport` API loads `.ts` config and setup files), `vitest` for tests.

**Spec:** `docs/superpowers/specs/2026-11-18-uilint-design.md`

## Global Constraints

- Node `>=20`. ESM only (`"type": "module"`).
- Exit codes: `0` no errors (warnings allowed), `1` one or more errors, `2` the tool failed (page didn't load, setup threw, bad config, layout never settled).
- Default viewports `375, 768, 1280`; fixed viewport height `900`; device scale factor `1`.
- `--max` default `50`, errors listed first.
- uilint must never read an opt-out from the page's markup. No `data-uilint-*` attribute, no magic class. Exceptions come only from `uilint.ignore` and `uilint.baseline.json`.
- Output is text or JSON only. Never write or emit screenshots.
- Deterministic: the same page gives byte-identical output. Round every measured number to 0.01px in the page script, and sort every list by a stable key (never by insertion order of a `Set` built from async work).
- Precision before recall: when a rule is unsure, it reports nothing or a warning.
- npm name `uilint` is already taken by another package. Keep `"name": "uilint"` with `"private": true` and `"bin": { "uilint": "dist/cli.js" }`; the publish name is decided later.
- Rule names, exactly: `alignment`, `spacing`, `size-consistency`, `overflow`.
- Owner files, exactly: `uilint.config.ts` / `uilint.config.json`, `uilint.ignore`, `uilint.baseline.json`.

## Review Focus

1. **A page that never settles** (spinner, ticking clock, autoplay carousel): uilint must exit `2` within the stability timeout with a message naming a box that kept moving, never hang or report on a half-settled layout. Test in Task 9.
2. **Screen-reader-only text** (`.sr-only`: 1px box, `clip: rect(0 0 0 0)`, `overflow: hidden`): must not become a box, or every accessible app reports clipped text. Test in Task 8.
3. **Overlays opened by a setup script** (modal, dropdown, tooltip) on top of page content: overlap, alignment and spacing must not compare overlay boxes with page boxes underneath. Tests in Tasks 3, 7 and 8 (the `layer` field).
4. **Expired login session or a redirect** (`--profile` whose cookies expired lands on `/login`): the report must say the page landed somewhere else, so a clean login page isn't mistaken for a clean dashboard. An HTTP status of 400 or above exits `2`. Test in Task 12.
5. **Large pages** (a table with 2,000 rows): rules must finish in seconds, not minutes. Test in Task 3.

```ts
export type Severity = 'off' | 'warn' | 'error';
export type ActiveSeverity = Exclude<Severity, 'off'>;
export type RuleName = 'alignment' | 'spacing' | 'size-consistency' | 'overflow';
export interface Rect { x: number; y: number; width: number; height: number } // document coords, CSS px
export type BoxKind = 'text' | 'media' | 'control' | 'surface';
export interface Locator { selector: string; text: string | null; components: string[]; source: string | null }
export interface Box {
  id: number;                       // document order, 0-based
  kind: BoxKind;
  rect: Rect;                       // text: union of glyph rects; others: border box
  layoutRect: Rect;                 // text: rect grown vertically by half-leading; others: same as rect
  lines: Rect[];                    // text only, one per line; [] otherwise
  baseline: number | null;          // text only: first-line baseline y
  textAlign: 'left' | 'center' | 'right' | null; // text only, start/end/justify resolved
  containerId: number | null;       // nearest ancestor that is itself a box
  layer: number;                    // 0 page; n>0 fixed / dialog / popover layer
  tag: string;
  role: string | null;
  clipped: { x: number; y: number } | null; // text px hidden by an overflow ancestor
  ellipsis: boolean;
  locator: Locator;
}
export interface PageInfo { url: string; finalUrl: string; status: number | null; viewport: number; scrollWidth: number; clientWidth: number }
export interface Snapshot { page: PageInfo; boxes: Box[] }
export interface Finding {
  rule: RuleName;
  check: string;                    // e.g. 'left', 'gap', 'inset-x', 'height', 'clipped'
  severity: ActiveSeverity;
  message: string;                  // e.g. 'left edge 3px off from 4 stacked items'
  measured: number;
  expected: number | null;
  boxIds: number[];                 // offender(s) first
  peerIds: number[];                // the group it was compared with; may be []
}
export interface Violation {
  url: string;
  rule: RuleName; check: string; severity: ActiveSeverity; message: string;
  measured: number; expected: number | null;
  elements: Locator[];
  peers: Locator[];                 // at most 3
  peerCount: number;                // full size of the compared group
  viewports: number[];              // ascending
  count: number;                    // >1 after collapsing repeated items
  fingerprint: string;
  anchor: { y: number; x: number }; // offender position at its first viewport, for sorting
}
export interface Rule<O> {
  name: RuleName;
  defaults: O;
  check(snapshot: Snapshot, options: O, severity: ActiveSeverity): Finding[];
}
```

- Produces (`src/near-miss.ts`):
  - `interface NearMissWindow { min: number; max: number; maxRatio?: number }`
  - `isNearMiss(measured: number, expected: number, w: NearMissWindow): boolean`: true when `d = |measured - expected|` satisfies `d > w.min && d <= w.max` and, if `maxRatio` is set, `d <= maxRatio * |expected|`.
  - `dominant(values: number[], tolerance = 0.5): { value: number; count: number } | null`: groups values within `tolerance` of each other (sort, then sweep), returns the largest group's lowest value. Returns null if the largest group has fewer than 2 members or ties with another group.
  - `fmtPx(n: number): string`: at most 2 decimals, trailing zeros dropped, `px` suffix (`3 → "3px"`, `2.5 → "2.5px"`, `2.499 → "2.5px"`).
- Produces (`tests/helpers/boxes.ts`): `box(o: { x: number; y: number; w: number; h: number } & Partial<Omit<Box, 'rect'>>): Box`. Auto-incrementing `id`, `kind: 'surface'`, `layoutRect` = rect unless given, `containerId: null`, `layer: 0`, `tag: 'div'`, `locator.selector: '#b<id>'`, everything else empty/null/false. `resetBoxIds()` for `beforeEach`. Also `snap(boxes: Box[], page?: Partial<PageInfo>): Snapshot`, which fills a dummy `PageInfo` (`viewport: 1280`, `scrollWidth` = `clientWidth` = `1280`). Every rule test uses it.

### Task 3: Geometry relations

**Files:**
- Create: `src/geometry/relations.ts`
- Test: `tests/unit/relations.test.ts`

**Interfaces:**
- Consumes: `Box`, `Rect` (Task 1).
- Produces:
  - `interface Pair { a: Box; b: Box; gap: number }`: `a` above (stacked) or left of (row) `b`. `gap` is measured between `layoutRect`s.
  - `scopeKey(b: Box): string`: `` `${b.layer}:${b.containerId ?? 'root'}` ``. Boxes are only compared within one scope.
  - `contains(outer: Rect, inner: Rect, tol = 0.5): boolean`
  - `isWithin(box: Box, ancestorId: number, byId: Map<number, Box>): boolean`: walks `containerId`.
  - `stackedPairs(boxes: Box[], opts: { maxGap: number }): Pair[]`: for each box, its nearest box below in the same scope whose x-range overlaps by more than 0 and whose gap is between 0 and `maxGap` inclusive. Skips pairs where one rect contains the other. Sorted by `(a.id, b.id)`.
  - `rowPairs(boxes: Box[], opts: { maxGap: number }): Pair[]`: the same horizontally, using y-range overlap.
  - `chains(pairs: Pair[]): Box[][]`: follows `a → b` links into maximal sequences. A box with two incoming links starts a new chain. Ordered by first box id.

Approach: bucket by `scopeKey`, sort each bucket by the leading coordinate, and stop scanning once the gap exceeds `maxGap`. This keeps large pages fast.

### Task 4: `alignment` rule

**Files:**
- Create: `src/rules/alignment.ts`
- Test: `tests/unit/alignment.test.ts`

**Interfaces:**
- Consumes: `stackedPairs`, `rowPairs` (Task 3); `isNearMiss`, `fmtPx` (Task 1).
- Produces: `alignment: Rule<AlignmentOptions>` where `AlignmentOptions = { min: number; max: number; maxGap: number }`, defaults `{ min: 0.5, max: 4, maxGap: 48 }`. Default severity `'error'`.

Algorithm (glyph `rect`, not `layoutRect`):
1. Candidate edges per stacked pair: if both boxes are text, use only the edge matching their shared `textAlign` (`left`, `center-x` or `right`), and skip the pair if their alignments differ. Otherwise use all three. For row pairs: `top`, `bottom` and `center-y`, plus `baseline` when both are text.
2. If any candidate edge differs by `<= min`, the pair is aligned; skip it. Otherwise take the edge with the smallest difference; if `isNearMiss(diff, 0, ...)` against `[min, max]`, it's a near-miss pair.
3. Odd one out: per `(scope, edge)`, union boxes that are exactly aligned (`<= min`) on that edge into groups. For a near-miss pair, the offender is the box whose group is smaller; on a tie, it's `b` (lower or right). Peers are the other box's group.
4. Report each `(offender, edge)` once. `check` is the edge name. `message` is `` `${edge} edge ${fmtPx(d)} off from ${n} stacked items` `` (stacked) or `` `... from ${n} items in the row` `` (row), with `n` = peer count. `measured = d`, `expected = 0`.

### Task 5: `spacing` rule

**Files:**
- Create: `src/rules/spacing.ts`
- Test: `tests/unit/spacing.test.ts`

**Interfaces:**
- Consumes: `stackedPairs`, `rowPairs`, `chains`, `scopeKey` (Task 3); `isNearMiss`, `dominant`, `fmtPx` (Task 1).
- Produces: `spacing: Rule<SpacingOptions>` where `SpacingOptions = { min: number; max: number; maxRatio: number; maxGap: number; maxInset: number; minTextGap?: number; scale?: number }`, defaults `{ min: 0.5, max: 4, maxRatio: 0.25, maxGap: 96, maxInset: 64 }`. Default severity `'error'`.

Checks (all use `layoutRect`):
- `gap`: for each chain from stacked and row pairs with at least 2 gaps, `dominant(gaps)` must exist; each gap with `isNearMiss(gap, dominant.value, window)` is a finding. `boxIds = [a.id, b.id]`, `peerIds` = the rest of the chain. Message: `` `gap ${fmtPx(g)}, siblings use ${fmtPx(d)}` ``.
- `inset-x` / `inset-y`: for each `surface` box with children (`containerId` = its id), compute left/right insets from non-text children only (ragged text would cause false alarms) and top/bottom insets from all children. If both values are `<= maxInset` and `isNearMiss(smaller, larger, window)`, report `boxIds = [container.id]`, `measured = smaller`, `expected = larger`. Message: `` `left inset 13px, right inset 16px` `` (sides named by actual values).
- `min-gap` (only when `minTextGap` is set): a stacked pair of two text boxes with `gap < minTextGap`.
- `scale` (only when `scale` is set): any chain gap or inset that isn't within 0.5px of a multiple of `scale`.

- Produces:

  - Checks and messages:

Both use `check: 'spill'`. Message `extends 12px outside its container`.
    - `hscroll`: `page.scrollWidth > page.clientWidth + tolerance`. `boxIds` is up to 3 layer-0 boxes whose right edge passes `clientWidth`, largest overflow first. Message `page scrolls horizontally by 125px`.
    - `overlap`: two text or control boxes in the same layer, neither `isWithin` the other, whose intersection is more than `tolerance` in both width and height. Message `text overlaps another element by 8×14px`, `measured` = intersection area.
  - `RULES: Rule<any>[]` in order `[alignment, spacing, sizeConsistency, overflow]`, and `DEFAULT_SEVERITY: Record<RuleName, Severity>` (all `'error'`).
  - `runRules(snapshot: Snapshot, config: UilintConfig): Finding[]` runs each rule not set to `'off'` and returns findings sorted by `(rule order, boxIds[0], check)`.

### Task 8: In-page measurement

**Files:**
- Create: `src/browser/measure.page.js`, `src/browser/snapshot.ts`, `tests/helpers/server.ts`
- Test: `tests/browser/measure.test.ts`

**Interfaces:**
- Consumes: `Box`, `Snapshot`, `PageInfo` (Task 1).
- Produces:
  - `measure.page.js`: one function expression `(options) => ({ boxes, scrollWidth, clientWidth })` with no imports or outer references. `options = { exclude: string[] }`.
  - `captureSnapshot(page: Page, info: { url: string; status: number | null; viewport: number }, exclude: string[]): Promise<Snapshot>`. `finalUrl` comes from `page.url()`.
  - `startServer(root: string): Promise<{ url: string; close(): Promise<void> }>`, a static file server on a random port for tests.

What the page script must do (the body is the implementer's):
- Walk the DOM in document order, including open shadow roots. Skip `display:none`, `visibility:hidden`, `opacity:0` (own or inherited), zero-size boxes, boxes fully outside the document, boxes fully clipped by an ancestor, and subtrees matching any `exclude` selector. Skip visually-hidden text: an element of 1×1px or smaller, or one with `clip`/`clip-path` that hides everything.
- Kinds: `text` is each element's own non-whitespace text node run, measured with `Range.getClientRects()`. `rect` is their union and `lines` the individual rects. `layoutRect` grows `rect` vertically by `(lineHeight − glyphHeight) / 2` per side. `baseline` is the first line's top plus `fontBoundingBoxAscent` from `canvas.measureText` with the computed font. `media` is `img, svg, video, canvas, iframe, picture`. `control` is `button, input, select, textarea, [role=button], a` with a visible background or border. `surface` is any other element with a visible background color/image, border, outline or box-shadow. An `<svg>` subtree is one box.
- Coordinates in document space (add `scrollX`/`scrollY`), every number rounded to 0.01.
- `containerId`: the nearest ancestor box. A text run's container is the box of its element or of the nearest ancestor that is a box.
- `layer`: the nearest ancestor that is `position: fixed`, `dialog[open]`, `:popover-open`, `[aria-modal=true]`, or has role `dialog|alertdialog|menu|listbox|tooltip`. Layers are numbered 1, 2, ... in document order. Otherwise `0`.
- `clipped`: for text, the px of `rect` outside the padding box of the nearest ancestor with `overflow` other than `visible` (x and y separately). `ellipsis`: `text-overflow: ellipsis` and `scrollWidth > clientWidth` on the element. When `ellipsis` is true, `clipped` is null, so truncation is reported once as an ellipsis warning and not again as clipped text.
- `textAlign` resolves `start`/`end`/`justify` using `direction`. Justified text counts as `left` in LTR.
- `locator.text`: first 40 chars of trimmed visible text, with `...` if cut, or null. `locator.selector`: a unique id if it isn't auto-generated (`/\d{3,}|^:r/`). Otherwise try `tag.class.class` (at most 2 classes, skipping hashed ones matching `/^(css|sc|jsx)-|_[a-z0-9]{5,}$|^[a-z]+-[a-zA-Z0-9]{6,}$/`), then the same with `:nth-of-type(n)`, then prefix the nearest ancestor's selector with ` > `, up to 4 levels, until the selector matches exactly one element.
- `locator.components`: from the `__reactFiber$*` property on the element, walk `.return` and collect up to 3 names (`type.displayName || type.name`) of non-host fibers, nearest first. Skip names that start with a lowercase letter or are React internals (`Fragment`, `Suspense`, `StrictMode`, `Provider`, `Consumer`, `ForwardRef`, `Memo`). `locator.source`: from the nearest component fiber, use `_debugSource.fileName:lineNumber` (React 18) if present. Otherwise take the first frame in `_debugStack.stack` (React 19) not under `node_modules`, strip the origin and query string, and keep `path:line`. Null when neither is present.
- Never read any `data-uilint*` attribute.

    `rule | matcher | viewport | reason`. `rule` is a rule name or `*`. `matcher` is `component:Name`, `text:substring` or `selector:css`. `viewport` is a width or `*`. `reason` is required and non-empty. Example: `spill | component:CardHeader | * | badge sits on the corner on purpose`.
  - `interface IgnoreEntry { line: number; rule: RuleName | '*'; matcher: { type: 'component' | 'text' | 'selector'; value: string }; viewport: number | '*'; reason: string }`
  - `parseIgnore(text: string, file: string): IgnoreEntry[]`: throws `UilintError` `` `${file}:${line}: ...` `` on a malformed line or a missing reason. The `rule` field also accepts a `check` name such as `spill` or `ellipsis`, so the owner can ignore one overflow sub-check.
  - `loadIgnore(path: string): Promise<IgnoreEntry[]>`: a missing file gives `[]`.
  - `applyIgnores(vs: Violation[], entries: IgnoreEntry[]): { kept: Violation[]; used: Set<number> }`: an entry matches when its rule (or check) matches and any element's locator matches the matcher (component is in `components`, text is a substring of `text`, selector equals `selector`). A viewport-specific entry removes only that width, and the violation is dropped when no widths remain. `used` holds the matching entries' line numbers.
  - `BaselineFile = { version: 1; fingerprints: string[] }`. `loadBaseline(path): Promise<Set<string>>` (missing file gives an empty set; bad JSON throws `UilintError`), `writeBaseline(path, vs: Violation[]): Promise<void>` (sorted unique fingerprints, 2-space JSON, trailing newline), `applyBaseline(vs, set): { kept: Violation[]; baselined: number }`.
