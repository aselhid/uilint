uilint

A layout linter for coding agents. It measures the rendered page and reports near misses in spacing, alignment, size and overflow, as plain text.

uilint

  • Reports only near misses: 3px off is a mistake, 40px off is a choice.
  • Plain text output, no screenshots to pay for.
  • Exit code 1 until the layout is right.
